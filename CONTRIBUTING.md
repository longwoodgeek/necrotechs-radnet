# Contributing

We're interested in low-cost communications experiments, preservation, verification and documentation.

Please open an issue with a narrowly scoped proposal or a reproducible observation. For RF tests, include device/model, antenna, firmware, country/region, operating profile, route-isolation controls, power settings, approximate path/obstacles, independent source timestamps, and what was actually measured. Never submit private keys, active credentials, personal addresses or unredacted local-station data.

**Code contributions:** use standard tests, minimal dependencies, non-destructive defaults and a clear statement of live-hardware validation status. Claims of safety, compliance or reliability require evidence.

**Conduct:** constructive technical disagreement is welcome, including disagreement about AI involvement. Personal attacks, harassment, doxxing and exclusionary abuse are not.

This is a volunteer maker project, not an emergency dispatch service. Avoid proposing unsafe autonomous controls.
