# Security and disclosure

**No private Reticulum identities, credentials, active station serial numbers, passwords, coordinates, or private contact directories belong in this public repository.**

Please do not post exploits, vulnerable target locations, private operational details, credentials, or personal information in public issues. Contact the maintainer privately through an appropriate GitHub account contact channel before sharing sensitive information. A dedicated security-reporting address has not been published yet.

For future releases: review `git log --all`, branches, commit attachments, screenshots and history before making anything public. If a secret is accidentally exposed, revoke/rotate the secret; deleting the file from HEAD alone is not sufficient.

This public repository was created from curated summaries, **not** as a mirror of the private SentinelLink development history.
